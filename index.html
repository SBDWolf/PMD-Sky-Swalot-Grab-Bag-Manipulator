Swalot's Grab Bag Manipulator

A web tool to generate Quicksave manipulations for Swalot's Grab Bag

Read this article if you need more information on how these work

Happen to carry gummies? Set a quantity under Gummies to feed and the solver piggybacks gummi eats onto the same quicksave run: between buying items it eats gummies whose outcome matches your target stat (or omniboost).

Fastest manipulation

Assumes that you are in a boss fight with one partner and the boss has been Stun Seeded. Every action costs 1 turn. Each row lists the moves to perform before eating that gummi. The order of moves within a row doesn't matter.

Already performed some turns? Enter the PRNG advances they cost under Advances before start. For example: throwing a Stun Seed from a quicksave with partner on wait there costs 5.
